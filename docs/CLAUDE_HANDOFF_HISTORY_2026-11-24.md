      - **GitHub:** only while GitHub sign-in is configured, and the login is on the allow-list when there is one.
      - Nothing is deleted.
    - **Unknown origins in bulk approval.** The button counted "Origin not recorded" records, and records that need an explicit size, which the store skips. One rule (`bulkApproval`) now gives the count, the confirmation and the submitted ids.
